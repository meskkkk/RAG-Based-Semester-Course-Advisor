# Course Descriptions (FICTIONAL sample catalog)

> All courses below are fictional sample data created for this assignment. They do not describe any real university program.

## CS101 - Introduction to Programming

This course introduces programming using Python for students with no prior experience. It covers variables, control flow, functions, lists, dictionaries, and file handling. Students learn to break a problem into steps and to test and debug their own code. Weekly lab exercises build up to a small final project such as a text-based game or a data summarizer. The course is the entry point to every computing track in the program.

## MATH101 - Calculus I

Calculus I presents limits, continuity, differentiation, and an introduction to integration for functions of one variable. Students practise applying derivatives to optimisation and rate-of-change problems. The course also introduces series and basic numerical approximation. It builds the mathematical maturity needed for linear algebra and probability later in the program. Weekly problem sessions strengthen manual calculation skills.

## PHYS101 - Physics for Computing

Physics for Computing covers mechanics, electricity, magnetism, and waves with examples taken from computing devices. Students study circuits, signals, and the physical limits of storage and communication. Laboratory sessions use simple sensors and measurement tools. The course provides the physical background for later hardware and embedded systems courses. No physics beyond secondary school is assumed.

## ENG101 - Technical Writing

Technical Writing teaches students to write clear reports, emails, and documentation for technical audiences. Topics include structuring a report, citing sources, and writing readable code documentation. Students also practise giving short oral presentations. Peer review sessions help students improve their drafts. The skills learned here are used in the graduation project and in professional work.

## MATH102 - Discrete Mathematics

Discrete Mathematics introduces logic, sets, relations, functions, and proof techniques. It covers counting, recurrence relations, graphs, and trees. Students learn to write simple induction and contradiction proofs. The topics form the formal basis for algorithms and computer science theory. Many examples connect directly to programming problems.

## CS102 - Object-Oriented Programming

Object-Oriented Programming extends the first programming course with classes, objects, inheritance, and polymorphism. Students learn encapsulation, interfaces, exception handling, and unit testing. The course introduces common design patterns and version control with Git. Team assignments require students to design and implement a medium-sized application. It prepares students for data structures and software engineering.

## CS201 - Data Structures and Algorithms

Data Structures and Algorithms covers arrays, linked lists, stacks, queues, trees, hash tables, and graphs. Students analyse running time using Big-O notation and compare sorting and searching algorithms. The course introduces recursion, dynamic programming, and greedy methods. Programming assignments require efficient implementations and careful testing. It is a core prerequisite for machine learning, vision, and language processing courses.

## MATH201 - Linear Algebra

Linear Algebra covers vectors, matrices, systems of linear equations, determinants, and vector spaces. Students study eigenvalues, eigenvectors, orthogonality, and the singular value decomposition. Examples come from graphics, data compression, and machine learning. Students use Python libraries to verify results computed by hand. This course supplies the mathematical language of modern AI.

## MATH202 - Probability and Statistics

Probability and Statistics introduces random variables, common distributions, expectation, and variance. It covers sampling, confidence intervals, hypothesis testing, and simple regression. Students practise analysing real datasets with Python. The course emphasises how to reason about uncertainty and noisy measurements. It is required for machine learning, data mining, and natural language processing.

## CS202 - Databases

Databases introduces relational modelling, SQL, normalisation, and transaction processing. Students design a schema, write queries, and optimise them using indexes. The course also gives a short introduction to NoSQL stores and when they are useful. A term project connects a database to a small application. It supports courses in software engineering, data mining, and mobile development.

## CS203 - Computer Organization

Computer Organization explains how a processor executes programs, from logic gates to the instruction set. Topics include number representation, assembly language, pipelining, caches, and the memory hierarchy. Labs use a simulator and small hardware kits. Students learn to reason about performance at the hardware level. The course is the basis for operating systems and embedded systems.

## CS204 - Web Development

Web Development teaches the building of dynamic websites using HTML, CSS, JavaScript, and a server-side framework. Students learn about HTTP, REST APIs, sessions, and basic web security. The course includes responsive design and deployment to a cloud host. Each student builds a complete web application connected to a database. It is a useful foundation for mobile development and software engineering projects.

## CS205 - Operating Systems

Operating Systems covers processes, threads, scheduling, synchronisation, memory management, and file systems. Students write programs that use system calls and concurrency primitives. The course explains deadlocks and how an operating system prevents or recovers from them. Labs use a Linux environment and a small teaching kernel. It leads to computer networks and cybersecurity.

## CS301 - Machine Learning

Machine Learning introduces supervised and unsupervised learning, including linear models, decision trees, support vector machines, and clustering. Students study model evaluation, overfitting, regularisation, and feature engineering. Practical work uses Python and scikit-learn on real datasets. The course ends with a project that compares several models on a problem chosen by the student. It is the entry point to deep learning and applied AI.

## CS302 - Software Engineering

Software Engineering covers requirements, design, testing, and maintenance of larger software systems. Students work in teams using agile methods, issue tracking, and continuous integration. The course introduces UML modelling and code review practice. A semester project delivers a working product to a simulated client. It prepares students for the graduation project.

## CS303 - Computer Networks

Computer Networks studies how data moves across the internet using the layered protocol model. Topics include TCP and IP, routing, DNS, wireless links, and network programming with sockets. Labs use packet capture tools to observe real traffic. Students configure small virtual networks and measure their performance. The course is a prerequisite for cybersecurity.

## CS304 - Image Processing and Computer Vision

Image Processing and Computer Vision covers filtering, edge detection, feature extraction, and geometric transformations. Students learn classical methods for object detection and tracking, and are introduced to convolutional neural networks. Programming work uses Python and OpenCV. A final project builds a simple vision application such as a lane detector or a document scanner. The course suits students interested in AI, robotics, and assistive technology.

## CS305 - Natural Language Processing

Natural Language Processing introduces tokenisation, language models, text classification, and sequence labelling. Students study word embeddings, attention, and the transformer architecture at a practical level. Assignments use Python and open-source libraries on English and Arabic text. The course discusses evaluation, bias, and the handling of multilingual and code-switched text. It suits students interested in chatbots, search, and language technology.

## CS306 - Data Mining

Data Mining covers methods for finding patterns in large datasets, including association rules, clustering, and anomaly detection. Students learn data preparation, feature selection, and the evaluation of mined patterns. Projects use SQL and Python on public datasets. The course also discusses privacy and ethical issues in the use of personal data. It leads to the big data analytics course.

## CS307 - Embedded Systems

Embedded Systems teaches the design of software for microcontroller-based devices. Topics include interrupts, timers, serial communication, sensor interfacing, and real-time scheduling. Weekly labs use ESP32 boards and common sensors. Students build a complete device that senses its environment and reports over a wireless link. The course suits students interested in robotics, IoT, and wearable devices.

## CS310 - Introduction to Data Science

Introduction to Data Science teaches the full workflow from data collection and cleaning to analysis and communication. Students use Python, pandas, and visualisation libraries on real datasets. The course introduces notebooks, reproducibility, and basic predictive modelling. Group projects present findings to a non-technical audience. It suits students who want a practical entry into data-driven work.

## CS401 - Deep Learning

Deep Learning covers neural networks, backpropagation, convolutional and recurrent architectures, and transformers. Students train models with PyTorch or TensorFlow and learn practical techniques such as normalisation, augmentation, and transfer learning. The course discusses training at scale and deployment on limited hardware. A final project reproduces and extends a recent research result. It builds directly on machine learning.

## CS402 - Cybersecurity

Cybersecurity introduces threats, vulnerabilities, cryptography, authentication, and secure system design. Students practise defensive techniques in controlled lab environments. Topics include web application security, network defence, and incident response. The course also covers the legal and ethical responsibilities of security professionals. It builds on the networks course.

## CS403 - Mobile Application Development

Mobile Application Development teaches the design and implementation of apps for Android and cross-platform frameworks. Students learn user interface design, local storage, networking, and the use of device sensors. Each team builds and publishes a working app that connects to a back-end service. The course covers testing, accessibility, and app store requirements. It combines the web and database courses into one practical project.

## CS404 - Big Data Analytics

Big Data Analytics studies the tools and architectures used to process data that is too large for a single machine. Topics include distributed file systems, MapReduce, Spark, and stream processing. Students run analyses on a cluster and tune them for performance. The course also covers data pipelines and data quality. It builds on data mining.

## CS490 - Graduation Project I

Graduation Project I is the first half of a two-semester capstone project done in a small team. Students choose a topic, review the literature, define requirements, and produce a design and a working prototype. Progress is evaluated through proposals, reports, and a mid-year presentation. A faculty supervisor guides each team. The project continues in Graduation Project II.

## CS491 - Graduation Project II

Graduation Project II completes the capstone project started in the previous semester. Teams finish the implementation, run evaluation experiments, and write a final report. The course ends with a public demonstration and an oral examination. Students are assessed on technical quality, teamwork, and communication. Successful completion is required for graduation.

## HUM401 - Professional Ethics

Professional Ethics examines ethical issues faced by engineers and computer scientists. Topics include privacy, fairness in algorithms, intellectual property, safety, and responsible use of AI. Students analyse real case studies and write short position papers. The course also covers professional codes of conduct and workplace responsibilities. It is open to final-year students in any semester.
